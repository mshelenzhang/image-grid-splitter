# Image Grid Splitter ✂️
**[English](./README.md) · 中文**

**一款注重隐私的浏览器端合并图切分工具，可以将合并图片快速拆分为独立、可继续使用的图片。**

项目来源于真实的内容生产需求，并通过 AI 辅助产品开发流程持续迭代完成。

> **公开产品案例。** 生产源码及具体实现细节保持私有。

## ✨ 它能做什么

Image Grid Splitter 用于将一张包含多个画面的合并图片，在浏览器中直接拆分成独立图片。

它主要解决内容生产过程中，多张视觉内容被生成或组合在同一张图片后，需要快速拆分、整理并继续发布或编辑的问题。

### 主要功能

- 🔍 自动识别图片布局
- ↔️ 支持拖动分割线进行精细调整
- 🖼️ 支持二宫格、四宫格
- 🧩 支持横向与纵向混合布局
- ⬜ 智能处理画面留白
- 🏷️ 支持按顺序或主题批量命名
- 📥 支持单张图片下载
- 📦 支持批量下载
- 🔒 图片在浏览器本地处理

图片处理在浏览器本地完成，无需上传至外部图片处理服务器。

## 🖥️ 产品预览

产品采用简单的三步工作流：

**上传与识别 → 调整与命名 → 下载成品**

## 💡 为什么做这个产品

这个项目来源于我自己内容生产过程中反复遇到的一个实际问题。

合并图很适合视觉内容的生成与整理，但后续如果每次都需要人工重新裁切成独立图片，就会产生大量重复操作。

与其不断重复解决同一个问题，我选择把这个流程做成一个小产品。

项目最初是一个本地小工具，之后逐步迭代成浏览器产品，并加入自动识别、交互式调整、批量命名、导出控制以及浏览器本地处理等能力。

## 🛠️ 产品架构

当前工作版本主要使用：

**HTML5 · CSS3 · 原生 JavaScript · Canvas API · File API**

产品保持轻量化设计：

- 无应用框架
- 无数据库
- 无外部图片处理 API
- 无需 API Key
- 图片处理无需上传服务器

这样的架构让工具保持轻量、便携，并尽可能减少图片数据离开用户设备的需要。
